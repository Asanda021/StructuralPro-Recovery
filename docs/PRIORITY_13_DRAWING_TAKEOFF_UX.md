# Priority 13 — Drawing & Takeoff UX

## هدف
تبدیل متره از نقشه از مجموعه‌ای از primitiveها به یک گردش‌کار نقشه‌محور، قابل بازبینی و قابل اتصال به BOQ.

## مسیر کاربر
PDF → بازکردن نقشه → صفحه → Zoom/Pan → کالیبراسیون → اندازه‌گیری → ثبت → بازبینی → ویرایش/حذف → Undo/Redo → اعتبارسنجی → BOQ-ready row

## قابلیت‌های این مرحله
- نمایش PDF صفحه‌به‌صفحه با Zoom/Pan و Fit-to-page
- کالیبراسیون واقعی با رابطه «پیکسل ↔ متر»
- متره طولی، سطحی و شمارش
- یادداشت/Markup روی نقشه
- شناسه پایدار برای هر متره
- Source Link شامل فایل، صفحه و شناسه متره
- جلوگیری از دوباره‌شماری بر اساس source
- جدول بازبینی متره‌ها
- حذف، Undo و Redo
- اعتبارسنجی قبل از خروجی
- تبدیل مستقیم session به ردیف BOQ از طریق TakeoffWorkflow.graphical_rows()
- نگهداری snapshot برای Revision/Comparison
- ذخیره و بازیابی session به JSON

## مرزهای فنی
- محاسبات هندسی در core و مستقل از Qt هستند.
- PyMuPDF فقط برای نمایش PDF استفاده می‌شود.
- DWG/IFC در این مرحله دوباره‌نویسی نشده‌اند؛ از adapterهای موجود استفاده می‌کنند.
- این مرحله طراحی سازه نیست؛ فقط تجربه و زنجیره متره نقشه‌محور را بالغ می‌کند.

## معیار پذیرش
1. کاربر بتواند نقشه را باز و صفحه را عوض کند.
2. کاربر بتواند مقیاس را با یک فاصله معلوم کالیبره کند.
3. طول/مساحت/شمارش با منبع و صفحه ثبت شوند.
4. آیتم ثبت‌شده قابل حذف و Undo/Redo باشد.
5. منبع تکراری باعث خطای دوباره‌شماری شود.
6. خروجی متره مستقیماً در قالب ردیف BOQ قابل تحویل باشد.
7. session قابل serialize/restore باشد.
8. تست‌های Priority 13 و تست‌های قبلی بدون regression سبز باشند.
