# P551-P560 — Graphical PDF Measurement Engine

## هدف
ایجاد موتور اندازه‌گیری گرافیکی برای PDF که فقط بر پایه شواهد هندسی صریحِ استخراج‌شده از PDF کار کند.

## قابلیت‌های این فاز
- اندازه‌گیری طول خط و polyline
- اندازه‌گیری مساحت polygon
- اتصال هر اندازه‌گیری به Project / Revision / Source / Page / Element
- الزام calibration صریح و دارای منبع
- fingerprint قطعی evidence
- fail-closed برای scale نامعتبر، مختصات غیرعددی/غیرفینیت و evidence ناقص

## اصل مهم
این لایه PDF را به‌صورت جادویی تفسیر نمی‌کند. تشخیص هندسه، مقیاس، متن یا عناصر ساختمانی باید از upstream extractor با evidence واقعی وارد شود. اگر calibration یا هندسه صریح وجود نداشته باشد، اندازه‌گیری انجام نمی‌شود.

## واحدها
این API مقدار طول را با ضریب خطی calibration و مساحت را با توان دوم همان ضریب محاسبه می‌کند. واحد نهایی باید توسط قرارداد بالادستی مشخص و مستند شود؛ این فاز واحد مهندسی پنهان فرض نمی‌کند.

## معیار پذیرش
1. طول بر اساس نقاط صریح و calibration محاسبه شود.
2. مساحت polygon deterministic باشد.
3. تغییر source/calibration باعث fail-closed شود.
4. fingerprint evidence deterministic باشد.
5. هندسه نامعتبر یا scale غیرمثبت پذیرفته نشود.
6. هیچ مقدار مهندسی یا هندسه‌ای از روی حدس تولید نشود.
