# P50 — Competitive Attack Plan

The benchmark covers PlanSwift, Kreo, STACK, Autodesk Takeoff, Buildxact and relevant Iranian tools through evidence supplied by official documentation, verified product behavior or documented user evidence.

The system records where StructuralPro can outperform (offline-first workflow, deterministic evidence, broad quantity/estimate contracts and local AI boundaries) and where it should not claim parity without evidence. It never invents competitor features, prices or performance.
