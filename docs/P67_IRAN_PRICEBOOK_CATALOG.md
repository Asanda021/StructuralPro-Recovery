# P67 — Iranian Pricebook Catalog

کاتالوگ اخیر فهرست‌بهای ابنیه اکنون سال‌های ۱۳۹۹ تا ۱۴۰۴ را پوشش می‌دهد.

این تغییر فقط پوشش نسخه/منبع را کامل می‌کند و **هیچ نرخ ساختگی** وارد موتور برآورد نمی‌کند. برای هر سال، فایل واقعی PDF/Excel باید دریافت، hash و ingestion شود تا تعداد ردیف‌ها و اتصال ۱۰۰٪ ردیف‌ها به موتور قابل اثبات باشد.

پس از دریافت فایل خام، ingestion موجود باید برای هر ردیف کد، شرح، واحد، مبلغ، فصل، سال، نسخه و hash منبع را ثبت کند و mapping نامطمئن را به review بفرستد.
