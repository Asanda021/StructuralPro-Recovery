## محدوده واقعی

## بررسی مستقیم GitHub

برای HEAD هر سه PR، پاسخ API وضعیت‌های Commit و اجرای Workflow برابر **صفر** بود. مقدار `mergeable=true` فقط نبود تعارض فوری است و **به معنی پذیرش آزمایشی یا اجازه ادغام نیست**.

## آزمون محلی واقعی

- `pytest -q tests/test_windows_acceptance_gate.py` → **۷ موفق**.
- اجرای ابزار روی Checkout فعلی Linux → **BLOCKED_MISSING_DEPENDENCIES** با خروجی **۲**.
- سه وابستگی نصب‌نشده: `PySide6`، `arabic_reshaper` و `bidi`.
- شمار فایل‌های Workflow قرنطینه‌شده: **۱۹۳**؛ هیچ Workflow فعالی در مسیر `.github/workflows` اضافه نشده است.
- ابزار هرگونه Workflow فعال و Symlink در مسیر آن را رد می‌کند و به‌دنبال نبود Qt/PDF، نتیجه ساختگی PASS تولید نمی‌کند.
- نمونه فنی جداگانه PyMuPDF Story توانست PDF فارسی چهارصفحه‌ای را بدون وابستگی bidi رسم کند؛ اما جهت جدول و ساختار انتخاب/استخراج متن هنوز تأیید نشده است. این نمونه **جایگزین موتور خروجی پروژه نشده** و جزء پذیرش نهایی نیست.

## آنچه اسکریپت در Windows انجام می‌دهد

1. بررسی ایمن‌بودن مخزن: صفر Workflow فعال و ۱۹۳ Workflow در قرنطینه.
2. بررسی بسته‌های نصب‌شده بدون دانلود/نصب خودکار.
3. اجرای Qt در یک پردازش جدا و ایجاد پروژه موقت با SQLite، نمایش پنجره واقعی متره دستی، ثبت تصویر PNG.
4. ساخت یک PDF فارسی واقعی از Exporter موجود؛ بررسی بازشدن، متن قابل انتخاب و خروجی تصویری صفحه اول.
5. ثبت گزارش JSON، لاگ و خروجی‌ها با وضعیت دقیق؛ حتی در صورت موفقیت فنی، **بازبینی بصری انسان همچنان الزامی** است.

## حد و مرز پذیرش

این آزمون **جایگزین تست رابط اصلی ۲۳ تب، PDF/DWG/IFC، فونت فارسی Word Windows یا همه فرم‌های ۱۳ عملیات** نیست. برای تأیید PRها باید آزمون‌های مرتبط، داده پنج‌طبقه، آزمون ذخیره و خروجی و بررسی تصویری روی Windows واقعی تکمیل شوند.

**حکم فعلی: `NOT MERGE READY`**؛ `main` و همه PRها محفوظ؛ Build/Release ممنوع.

## نحوه اجرا در رایانه شخصی Windows

بعد از دریافت Clone مخزن و نصب دستی وابستگی‌ها:

```powershell
python scripts/windows_acceptance_gate.py --repo . --out-dir qa/windows
```

یا در PowerShell:

```powershell
.\scripts\run_windows_acceptance.ps1
```

بسته‌ها را تنها در محیط مورداعتماد و با نسخه‌های سازگار پروژه نصب کنید. فایل‌های `qa/windows` را برای بازبینی تصویری نگه دارید و **صرف خروجی PASS را مجوز Merge فرض نکنید**.
