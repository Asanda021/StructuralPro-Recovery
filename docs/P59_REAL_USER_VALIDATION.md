# P59 — Real User Validation

این فاز قرارداد ارزیابی واقعی توسط کاربر/بازبین انسانی را اضافه می‌کند.

برای هر نمونه، پروژه، بازبین، task، مقدار مرجع انسانی، مقدار سیستم، واحد، منبع شواهد، زمان مشاهده و disposition ثبت می‌شود.

خروجی شامل تعداد نمونه، میانگین خطای نسبی و fingerprint است. داده بدون شواهد یا مقادیر نامعتبر fail-closed می‌شوند.

این فاز **هیچ کاربر واقعی، پروژه واقعی، دقت واقعی، رضایت، پذیرش یا KPI بازار را جعل نمی‌کند**. نتیجه معتبر فقط پس از ورود شواهد واقعی از پروژه‌ها و بازبین‌های واقعی به دست می‌آید.
