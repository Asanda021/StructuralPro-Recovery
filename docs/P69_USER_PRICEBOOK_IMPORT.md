# P69 — User Pricebook Import

کاربر می‌تواند فهرست‌بهای شخصی/سازمانی خود را وارد کند.

فرمت‌ها: XLSX, XLS, CSV, JSON, PDF.

جریان: انتخاب فایل → سال/رشته → SHA-256 → استخراج → نمایش تعداد ردیف و خطا → تأیید → ثبت نسخه → اتصال به موتور برآورد.

PDF ابتدا needs_review است و بدون تأیید کاربر قطعی نمی‌شود.
