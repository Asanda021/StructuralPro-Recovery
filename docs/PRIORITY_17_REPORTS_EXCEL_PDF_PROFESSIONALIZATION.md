# Priority 17 — Reports / Excel / PDF Professionalization

## هدف
تبدیل خروجی گزارش از یک export ساده به گزارش حرفه‌ای، ساختاریافته و قابل استفاده در دفتر فنی.

## خروجی‌ها
- Excel سه‌برگه: «ریز متره»، «خلاصه»، «اطلاعات»
- RTL واقعی در workbook و alignment راست‌چین
- ستون‌های استاندارد و ترتیب پایدار برای BOQ
- PDF افقی A4 برای جدول‌های عریض
- PDF با font Unicode در صورت وجود فونت مناسب سیستم و fallback امن
- CSV با UTF-8 BOM برای سازگاری با Excel فارسی
- DOCX قبلی حفظ شده و از همان قرارداد ستون‌ها استفاده می‌کند

## قرارداد گزارش
ProjectReport اکنون metadata، ستون‌های استاندارد، validation و export واحد را مدیریت می‌کند.

## مرزبندی
این مرحله محاسبات جدید یا قیمت آنلاین اضافه نمی‌کند؛ فقط ارائه، خروجی و قابلیت استفاده حرفه‌ای از داده موجود را ارتقا می‌دهد.
