# P60 — Release Package & Installation Readiness

قرارداد Evidence برای آماده‌سازی انتشار اضافه شد. هر Artifact باید نام، نسخه، SHA-256، پلتفرم و زمان مشاهده داشته باشد و هر تست نصب باید به Artifact مشخص و شواهد نصب متصل باشد.

تصمیم‌ها: go برای همه تست‌های pass، needs_evidence برای شواهد ناقص یا تأییدنشده، و no_go برای هر تست fail.

این فاز ادعای انتشار عمومی یا نصب موفق روی دستگاه واقعی را بدون شواهد واقعی مطرح نمی‌کند.
