# P70 — Official Pricebook Sources

کاتالوگ منابع رسمی فهرست‌بهای ابنیه برای سال‌های ۱۳۹۹ تا ۱۴۰۴ تکمیل شد.

- برای سال‌های ۱۴۰۱، ۱۴۰۳ و ۱۴۰۴ صفحه رسمی SAMA ثبت شده است.
- برای ۱۳۹۹، ۱۴۰۰ و ۱۴۰۲ منبع رسمی/پرتال سازمان ثبت شده و تا دریافت مستقیم صفحه/بایت فایل، وضعیت «official-portal» حفظ می‌شود.
- هیچ نرخ عددی داخل کد قرار نگرفته است.
- دریافت فایل خام باید با SHA-256، نسخه، سال، رشته و provenance ثبت شود؛ سپس ingestion موجود ردیف‌ها را به موتور برآورد متصل می‌کند.

این تفکیک عمداً جلوی ادعای «داده کامل» بدون دریافت و hash فایل واقعی را می‌گیرد.
