# P99–P101 Production Data Completion
P99 materializes official artifacts and records SHA-256, size, source URL and local path. HTML/error pages are rejected.
P100 requires all 24 cells: 1399–1404 × ابنیه, تاسیسات مکانیکی, تاسیسات برقی, مرمت بناهای تاریخی. Every cell must have a real source URL, local artifact path, SHA-256 and positive extracted row count.
P101 normalizes code/unit keys, rejects conflicts and unresolved takeoff items, and prices full-building takeoff rows while preserving source provenance.
No synthetic pricebook data is shipped as production data. Gates fail closed until real official artifacts are supplied and extracted.
