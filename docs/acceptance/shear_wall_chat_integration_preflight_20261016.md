# StructuralPro — تحویل Chat، آماده‌سازی اتصال دیوار برشی بدون تغییر Work

## وضعیت قابل استناد

- مبنای منبع: بکاپ مخزن در Commit `52d2b20beed1a9de57afcf170c5b81f260942a97` از Dropbox.
- موتور مرجع Chat: ZIP به SHA-256 `a1374a8d730fe1017e9b03205d6295a6f7cc273f7cac40d2c7e407786b8cfcf5`؛ سورس `shear_wall_specialist_chat.py` بدون تغییر کپی شد.
- این تحویل روی شاخه Work یا PR #18 نوشته **نشده**؛ همه تغییرات در کپی محلی ایزوله هستند.
- خروجی: Adapter آماده‌سازی **فقط خواندنی** و ردیف‌های پیشنهادی قابل ممیزی؛ SQLite، گردش بازبینی، اصلاحیه، فرم Qt، گزارش و ثبت نهایی هنوز متصل نشده‌اند.

## قرارداد عددی

- فقط خروجی `concrete_net`، `formwork_main`/`formwork_edge` دارای مقدار مثبت و گروه‌های `rebar_*` به ردیف قابل بررسی تبدیل می‌شود.
- حجم ناخالص، کسورات بازشو و اشتراک در شواهد بتن خالص ثبت می‌شوند؛ به‌صورت ردیف مثبت یا منفیِ قابل پرداخت وارد BOQ نمی‌شوند.
- خروجی حسابداری صرفاً پیشنهادی است: `price_code=None`، `unit_price=None`، `role=work`؛ جمع m3، m2، kg مستقل کنترل می‌شود و Decimal به رشته تبدیل می‌شود.
- بررسی شکل رکورد با `validate_commit_rows` موجود انجام می‌شود؛ `rebuild_project_boq` فقط **در حافظه** و روی Snapshot آزمایشی اجرا شده است.
- شناسه پروژه و منبع، هویت دیوار، رکورد عمومی قبلی، شناسه‌های BOQ و کسر اشتراک موجود کنترل می‌شوند.
- اصل موتور قادر نیست تداخل هندسی با ستون/تیر/پی را از ثبت‌های با محور/دستگاه مختصات متفاوت تشخیص دهد. بدون تطبیق مستقل و مدارک واقعی، ثبت قطعی ممنوع می‌ماند.
- تأییدکننده دیتایل‌های تو در تو و بازبین مستقل نباید یکی باشند؛ خودِ `review_reference` هنوز فایل مدرک/هش معتبر را اثبات نمی‌کند.

## دروازه‌های ادغام که هنوز باز هستند

۱. گواه هندسی و مالکیت بتن/میلگرد بین دیوار، ستون، تیر و فونداسیون با دستگاه مختصات/تراز مشترک.
۲. سازگارکردن داده موتور با قرارداد Review فعلی `ReviewedAECWorkflow` برای `shear_wall`، محافظت از داده‌های عمومی قدیمی، CAS و قفل مالی.
۳. ثبت نسخه‌دار و اصلاحیه با SHA-256 واقعی مدرک، بازبین مستقل و جلوگیری از تغییر هویت قطعه.
۴. فرم تخصصی فارسی راست‌به‌چپ، ذخیره SQLite و چهار صادرکننده مشترک.
۵. سناریوی یکپارچه پنج‌طبقه، آزمون Windows/Office واقعی و رگرسیون جامع.
