**گیت غیرویندوزی هنوز باز است:** شاهد کامل مستقل این ۳۷ خانواده و سناریوی یک ساختمان واقعی پنج‌طبقه با نقشه/مرز مالکیت/کسورات مصوب در دسترس نیست. موفقیت آزمون‌های مصنوعی این کمبود را رفع نمی‌کند. Windows/Office نیز جدا تأیید نشده‌اند؛ ادعای «فقط Windows باقی مانده» یا بسته‌شدن فاز ۱ صادر نمی‌شود.
