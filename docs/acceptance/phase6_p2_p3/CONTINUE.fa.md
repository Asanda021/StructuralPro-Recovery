- `tests/test_phase6_p2_background_loader.py` و اصلاح آزمون `test_phase6_p2_real_ifc_3d.py` برای بازشدن ناهمگام QTest، عدم تغییر نشست مالی/متره، رد SHA غلط و لغو.
- **CI واقعی کد:** [#40337608667](https://github.com/Asanda021/StructuralPro-Recovery/actions/runs/40337608667)، Linux ۳۹ PASS و Windows ۳۹ PASS، صفر FAIL/ERROR. هشدارهای CI در لاگ مستقل باقی مانده‌اند.

## مهم‌ترین کارهای باز و ترتیب ادامه
**P6-2 همچنان PARTIAL**
1. بارگذاری هندسه چندبسته‌ای تدریجی با بودجه RAM و Cancel حین پیمایش/پردازش، نه فقط Worker غیرمسدودکننده و لغو منطقی.
2. E2 واقعی: اتصال state دوربین/طبقه/فیلتر/انتخاب به Session Snapshot نسخه‌دار موجود با کنترل پروژه، SHA و Revision؛ ساخت سیستم Backup دوم ممنوع.
3. Benchmark واقعی مدل‌های ۱، ۵، ۲۰، ۵۰ و ۱۰۰ طبقه با RAM، latency، آزمون لغو و اطلاعات سخت‌افزار مرجع؛ بدون حذف پنهانی اجزا.
4. تست پوشش بصری چندرشته‌ای و Windows interactive؛ عدم نمایش هندسه/عدد حدسی.

**P6-3 اکنون STARTED / PARTIAL**
1. اتصال **فعلیِ پنل مستقل** به `GraphicalTakeoffDialog`، IFC tree واقعی و BOQ واقعی پروژه؛ در این نوبت تغییر `app/graphical_takeoff.py` روی شاخه P6-3 ثبت نشده است. **هیچ ادعای چهارطرفه عملیاتی نکن.**
2. مرجع مجاز تأیید مستقلِ Reviewer/Evidence و stable BOQ row ID باید از Service/SQLite واقعاً به index تزریق شود؛ `item_no` یا `price_code` به تنهایی هویت پایدار BOQ نیست.
3. Inspector با منبع، SHA، عضو، ردیف و Revision معتبر؛ انتخاب 2D/3D↔tree↔BOQ، امتناع بی‌هندسه، نقشه تغییرکرده و داده مشترک.
4. اتصال بازیابی نشست و آزمون عدم تغییر BOQ/قیمت/Revision در flow واقعی برنامه؛ CI پنل مستقل فعلاً کافی برای COMPLETE نیست.
