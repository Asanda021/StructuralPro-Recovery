# StructuralPro — توسعه مستقل در Chat: هسته محاسبه شیب‌بندی خطی (نسخه آزمایشی)

**مبنای کد:** Commit `67afa178b759f4827c334e15d2a5b73072f1cb8e` (بکاپ Dropbox تأییدشده).
**وضعیت:** توسعه جدا از Work، فاقد Commit در GitHub و فاقد ادغام در PR شماره ۱۸.
**دامنه:** یک ناحیه افقی مستطیلی و سطح رویه با شیب خطیِ مستند در راستای `x` یا `y`، بر روی تراز مبنای ثابت.

## چه چیز واقعاً ساخته شد؟

- ماژول **واقعی Python** در `core/takeoff/slope_linear_geometry.py`: محاسبه مساحت و حجم ناخالص، کسر دقیق حجم بازشو از انتگرال ضخامت خطی همان محدوده، مساحت و حجم خالص، کنترل تکرار شناسه و منبع و منع هم‌پوشانی بازشوها.
- اعداد با `Decimal` و ابزار دقت ۵۱۲ رقمی موجود در پروژه پردازش می‌شوند؛ نمایش خروجی به‌صورت **رشتهٔ اعشاری دقیق** است، نه float. تبدیل یا گرد کردن پنهانی انجام نمی‌شود.
- یک ابزار خط فرمان `scripts/preview_slope_linear_geometry.py` برای دریافت JSON واقعی/مصنوعی و چاپ یا ذخیره پیش‌نمایش؛ ذخیره خروجیِ موجود را بازنویسی نمی‌کند.
- یک فایل نمونه با برچسب **مصنوعی** و مجموعه آزمون‌های واقعی در `tests/test_slope_linear_geometry_chat_20261016.py`.

### مرجع عددی نمونه

مستطیل `5×4 m` با ضخامت خطی از `0.1` به `0.3 m` در راستای x:

- مساحت ناخالص `20 m²` و حجم ناخالص `4 m³`.
- یک بازشوی `1×1 m` واقع در x=1..2 با متوسط ضخامت خودش `0.16 m`، حجم کسر `0.16 m³`.
- مساحت خالص `19 m²` و حجم خالص `3.84 m³`.

**فرمول ریاضی:** `t(x)=t_start+(t_end−t_start)×x/L`؛ حجم ناخالص سطح مستطیلی در راستای خطی `L×W×(t_start+t_end)/2` است. کسر بازشو با انتگرال مستقل تابع ضخامت در همان بازشو محاسبه می‌شود. استفاده از ضخامت متوسط *کل* سطح برای کسر بازشو نادرست است.

### چه چیز ساخته نشده؟

- **هیچ اتصال به فرم PySide6، دفتر SQLite، اصلاحیه، BOQ، قیمت، PDF/Excel/Word یا کدهای Work ندارد.** خروجی عمداً `boq_ready=false` است.
- برداشت از نقشه، شناسایی هویت فیزیکی بین چند رکورد، احراز واقعی مدرک یا تأییدکننده، شیب در دو جهت، سطح چندوجهی/منحنی، بازشوی غیرمستطیلی یا جزئی، نسبت اختلاط، وزن مصالح، خرید، ضریب پرت و پذیرش مهندسی واقعی وجود ندارد.
- برای کسر نامتناهیِ اعشاری که قابل نمایش دقیق در Decimal نیست، محاسبه ممکن است **Fail-Closed** شود تا مقدار تقریبی ساخته نشود.
- تا زمانی که در Work یک آداپتور امن برای `ReviewedAECWorkflow`، کنترل شناسه و منبع، SQLite/BOQ، فرم و چهار گزارش نوشته و آزموده نشده، این بخش «تکمیل شیب‌بندی» محسوب نمی‌شود.

## بازتولید در یک کپی مستقل از سورس StructuralPro

فایل‌های بسته را مطابق مسیر نسبی در ریشه سورس کپی کن و سپس:

```bash
PYTHONPATH=.:tests python -m pytest -q tests/test_slope_linear_geometry_chat_20261016.py
PYTHONPATH=.:tests python scripts/preview_slope_linear_geometry.py --input examples/slope_linear_synthetic.json
```

یا در Windows (PowerShell) بعد از فراهم بودن Python و وابستگی‌های معتبر:

```powershell
$env:PYTHONPATH = '.;tests'
python -m pytest -q tests/test_slope_linear_geometry_chat_20261016.py
python scripts/preview_slope_linear_geometry.py --input examples/slope_linear_synthetic.json
```
