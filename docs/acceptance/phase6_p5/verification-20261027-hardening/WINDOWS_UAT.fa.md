# گیت پذیرش فیزیکی Windows — اجرا نشده

این چک‌لیست شاهد PASS نیست. آزمایشگر باید نسخه Windows، دستگاه، GPU/درایور، تعداد نمایشگر، رزولوشن، مقیاس، Commit و Tree آزموده و نتیجه هر مرحله را ثبت کند. از پروژه و داده مصنوعی معتبر استفاده شود؛ Secret یا داده محرمانه در شواهد مخزن عمومی قرار نگیرد.

| سناریو | عمل قابل تکرار و نتیجه مورد انتظار | نتیجه/شاهد انسانی |
|---|---|---|
| شروع | همان Commit آزموده CI را اجرا کنید؛ پروژه P و پروژه دوم Q با عضو و Revision متمایز باز کنید | NOT VERIFIED |
| DPI و صفحه محدود | در مقیاس‌های ۱، ۱٫۵ و ۲ و صفحه ۱۰۲۴×۷۶۸ فرم‌ها را باز کنید؛ کنترل Save/Cancel/Commit باید قابل دسترس و متن فارسی خوانا باشد | NOT VERIFIED |
| Dock | پنل‌های اصلی 2D، 3D، Inspector و BOQ را Dock/Undock، جابه‌جا، ببندید و از منو دوباره باز کنید؛ انتخاب عضو و ردیف مستند حفظ شود | NOT VERIFIED |
| بازیابی | چیدمان را ذخیره و برنامه را بسته و دوباره باز کنید؛ فقط همان پروژه/منبع معتبر دوباره بارگذاری شود؛ SQL و BOQ به‌علت چیدمان تغییر نکند | NOT VERIFIED |
| دو نمایشگر | پنل شناور را میان دو نمایشگر با DPI متفاوت منتقل، نمایشگر را قطع و دوباره وصل کنید؛ پنل خارج صفحه نماند | NOT VERIFIED |
| Sleep | Sleep/Resume و اتصال مجدد نمایشگر را تکرار کنید؛ انتخاب معتبر حفظ یا در تغییر منبع صریحاً باطل شود | NOT VERIFIED |
| تعویض هویت | بین P و Q و Revisionهای مختلف بروید؛ BOQ/Viewer/Inspector پروژه قبلی نمایش داده نشود | NOT VERIFIED |
| W1 | تیر/ستون/MEP را باز کنید؛ Cancel تمیز، ویرایش ناتمام، رد/تأیید Discard، خاموش/روشن و Wizard تازه را اجرا کنید؛ داده قبلی بدون handoff تازه مجاز به نوشتن نشود | NOT VERIFIED |
| تأیید تیر | در پیام ثبت، منبع یا Revision را تغییر دهید؛ Yes نباید پیشنهاد منقضی را ثبت کند. محدودیت حذف فایل باز در Windows جداگانه ثبت شود | NOT VERIFIED |
| E4/E6 | جست‌وجوی فارسی/نیم‌فاصله و شناسه‌های مشابه را امتحان کنید؛ پیش‌نمایش و No گروهی نباید SQLite/BOQ را تغییر دهد؛ وابستگی‌ها باید در پیام دیده شوند | NOT VERIFIED |

برای هر شکست: ورودی، عمل دقیق، انتظار، نتیجه، تصویر بدون اطلاعات حساس و hash فایل ثبت شود. CI یا Qt offscreen جای آزمون فیزیکی یک/دو نمایشگر و پذیرش مهندسی مالک نیست.
