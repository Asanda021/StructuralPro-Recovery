## ایرادهای بازتولیدشده و اصلاح
۱. ورودی `float` یا `bool` در برخی مختصات، شمارش، ابعاد و نرخ/ضخامت مواد با `Decimal(str(value))` پذیرفته می‌شد. مرز عددی پوشش اکنون صریحاً `float` و `bool` را رد می‌کند؛ مقادیر متنی دقیق، `int` یا `Decimal` معتبرند. مستند بودن داده همچنان بر عهده منبع واقعی است.

۲. پیش‌نمایش پوشش پس از شکست اعتبارسنجی دیرهنگام، `ready=False` ولی همراه ردیف‌های محاسبه‌شده جزئی برمی‌گشت. اکنون برای هر خطای قراردادی `rows=[]` برگردانده می‌شود؛ هیچ کاندیدای مقدار ناقص نباید به‌عنوان محاسبه قابل استفاده دیده شود.

فایل‌های کد: `core/takeoff/interior_cover_detail.py` و `tests/test_cover_phase1_numeric_failclosed.py`. هش محتوای Git هر دو با نسخه محلی آزموده‌شده تطبیق داده شد.
