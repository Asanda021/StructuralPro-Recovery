# چک‌لیست کوتاه پذیرش مالک در Windows واقعی

این فهرست UAT فیزیکی است؛ PASS در Windows Server CI جای آن را نمی‌گیرد. در این مأموریت EXE/Installer ساخته نشده است. اجرا با checkout آزموده‌شده یا بسته آزمایشیِ بعداً صریحاً مجازشده انجام شود؛ ساخت بسته در این فهرست مجاز نمی‌شود.

نام دستگاه / Windows / GPU و نسخه Driver / RAM / DPI / SHA نسخه آزموده‌شده / تاریخ: …

| اقدام مالک | پذیرش | نتیجه / تصویر یا خطا |
|---|---|---|
| بازکردن همان پروژه در ۱۰۰٪، ۱۵۰٪ و ۲۰۰٪؛ بررسی فارسی/RTL، Ribbon، انتخاب و پنجره شناور | نوشته و دکمه حیاتی بریده یا ناخوانا نباشد؛ انتخاب و پنل‌ها کار کنند | انجام‌نشده |
| انتقال پنجره بین دو مانیتور واقعی با DPI متفاوت و قطع/وصل مانیتور دوم | پنجره و مودال قابل دسترسی بمانند؛ چیدمان قابل بازیابی باشد | انجام‌نشده |
| انتخاب عضو IFC در 2D، 3D، درخت و ردیف مرتبط BOQ؛ چرخش/بزرگ‌نمایی روی GPU دستگاه | شناسه همان عضو حفظ شود؛ هیچ مقدار بدون تأیید تغییر نکند | انجام‌نشده |
| ذخیره، بستن، بازگشایی؛ Sleep و Resume در پروژه باز | پروژه/Revision و انتخاب معتبر بمانند؛ توقف یا Crash نباشد | انجام‌نشده |
| بازکردن PDF/XLSX/DOCX/CSV فارسی نمونه و تأیید خوانایی شخصی | متن، جدول و فونت خوانا؛ کنترل Office و چاپ واقعی طبق فاز ۸ مستقل است | انجام‌نشده |
| تأیید تجربه کار و تصمیم مالک | ثبت ACCEPT / REJECT با SHA و موارد دقیق باقی‌مانده | امضا نشده |

فقط موارد متناسب با سخت‌افزار موجود اجرا شوند؛ «نداشتن مانیتور دوم» باید NOT EXECUTED ثبت شود. هیچ مورد اجرا‌نشده‌ای PASS نیست. امضای این فهرست به‌تنهایی اجازه Merge/Release/EXE یا شروع فاز ۷ نیست.
