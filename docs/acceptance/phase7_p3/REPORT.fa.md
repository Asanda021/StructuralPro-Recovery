## کد تحویلی فعلی
- TemplateStore جدا از SQLite/BOQ؛ schema دو، مهاجرت صریح schema یک، نسخه‌های append-only با هش و زنجیره نسخه، ثبت‌کننده/علت/زمان UTC. ظرفیت فعلی ۱۰۰ نسخه قالب.
- ReportLayout موجود: عنوان، ستون و ترتیب، گروه، سربرگ/پابرگ، فیلتر طبقه/رشته/زون/نسخه؛ جمع Decimal با تفکیک واحد و بدون ساخت قیمت برای گزارش مقداری.
- کنترل PNG معتبر و محدود، کپی به دارایی پروژه و ارجاع محتوایی SHA؛ رد مسیر بیرون پروژه، symlink و لوگوی تغییرکرده.
- یک فرمان برای چند گزارش؛ PDF/XLSX/DOCX/CSV از صادرکننده‌های موجود؛ قالب A4/A3 و افقی/عمودی، Manifest هش/اندازه/نسخه/منبع/زمان/وضعیت بازبینی، staging و انتشار اتمیک.
- منبع Drawing از نشست و رسیدهای اصلی بازاعتبارسنجی می‌شود؛ گزارش برآورد فقط با audit_boq و فهرست‌بهای تأییدشده، بدون recalculate یا نوشتن مالی.
- CustomReportDialog واقعی RTL، انتخاب ستون و ترتیب، قالب و نسخه، فیلتر، پیش‌نمایش جدول فقط‌خواندنی، انتخاب لوگو، ذخیره/بازیابی و صدور جداگانه طبقات. اتصال به تب گزارشات، Ribbon و مسیر قدیمی طراحی گزارش؛ چیدمان قدیمی فقط برای مهاجرت خوانده می‌شود.
- تنظیمات صفحه به صادرکننده موجود افزوده شده‌اند؛ defaults قبلی محفوظ هستند. CSV صرفاً داده متنی است، نه RTL بصری.

## آزمون و محدودیت فعلی
پیش از قطع محیط محلی، چند دور RED/GREEN واقعی اجرا شد. آخرین مشاهده کامل شامل ۲۰ آزمون موفق و یک شکست در انتخاب QVariant tuple برای آزمون UI بود؛ مشکل findData با انتخاب و مقایسه صریح داده/متن اصلاح شد. نسخه نهایی پس از این اصلاح و تکمیل فیلتر/ردیف‌های Manifest هنوز به اجرای CI همین Commit نیاز دارد؛ شمارش اجرای قبلی به آن نسبت داده نمی‌شود.

محیط اجرای محلی در ادامه با خطای «No usable execution environment is available» قطع شد. برای از دست نرفتن کار، فایل‌ها از متن کد همین جلسه روی شاخه GitHub ثبت شدند. این ثبت، پذیرش یا اثبات برابری بایت‌به‌بایت با آخرین scratch نیست. مرجع ادامه، HEAD واقعی همین PR و CI آن است.

CI هدفمند Windows/Linux شامل P3 و نگهبان‌های اصلی P2/P1 و UI است. گیت جامع نیز همان runner اصلی Linux، سه shard Windows و union را حفظ می‌کند. برای ادعای پذیرش باید CI فعلی، بازخوانی چهارقالبی، تصاویر واقعی Native و PDF، دقت بلند/صفرابتدایی/ورودی مخرب، هم‌زمانی و بازبینی مستقل بررسی شوند. هیچ تستی برای سبزشدن حذف یا Skip نشود.
