- محاسبه مستقل هندسی: چهار طبقه هرکدام ۲۰ مترمربع؛ طبقه سوم ۱۹٫۷۵ مترمربع پس از کسر بازشو؛ جمع ۹۹٫۷۵ مترمربع. صرفاً Golden مصنوعی آزمون، نه برآورد ساختمان واقعی مشتری.
- بسته گزارش پنج‌صفحه‌ای با چهار قالب PDF/Word/Excel/CSV و Manifest به همراه SHA-256 مستقل بازخوانی می‌شود.
- بدون قیمت تأییدشده، برآورد باید رد شود و Digest ثابت بماند.
- فایل واقعی CSV نرخ ساختگی و صریح برای تست با واحد IRR، پنج کد مستقل و بازبینی واقعی در API مربوط به Pricebook؛ بازبین نگاشت مستقل.
- حساب معیار مستقل: ۲۰×۱۰ + ۲۰×۲۰ + ۱۹٫۷۵×۳۰ + ۲۰×۴۰ + ۲۰×۵۰ = **۲٬۹۹۲٫۵ ریال صرفاً آزمونی**. موتور Decimal با عدد مستقل تطبیق داده می‌شود.
- دوره شماره ۱ صورت‌وضعیت با مبلغ محاسبه‌شده، بازیابی SQLite و وضعیت LEGACY_RECORD_NOT_FINANCIALLY_APPROVED. دوره بدون تأیید پرداخت نباید به گزارش صورت‌وضعیت تأییدشده راه یابد.
- خروجی برآورد PDF و Excel با صادرکننده موجود و بازخوانی واقعی فایل؛ integrity_check و foreign_key_check SQLite و بازگشایی از سرویس دوم.
- سناریوهای منفی: تغییر منبع قیمت پس از تأیید، نبود بازبین، تلاش صدور یا محاسبه با مدرک نرخ دستکاری‌شده؛ بدون تغییر SQLite.
