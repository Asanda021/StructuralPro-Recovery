## تصمیم قطعی مالک و ترتیب اجرای قابل سنجش
**اولویت حیاتی مشترک P8/P2:**
- **P8/P2-A، موتور متره حرفه‌ای PDF/DWG/IFC:** تمام اجزای ساختمانی در محدوده مدارک داده‌شده شناسایی/تعیین‌تکلیف، هیچ حذف خاموش یا دوباره‌شماری، محاسبه هندسی و مهندسی دقیق و وابسته به نسخه با ممیزی مستقل. مرجع گیت T01–T12: `docs/acceptance/phase8_p2/TAKEOFF_100_PERCENT_EXECUTION_GATE_FA.md`. **ثبت گیت به معنای «متره کاملاً بهینه و پذیرفته شد» نیست**؛ دو ZIP واقعی خصوصی باید پاس شوند.
- **P8/P2-B، کنترل پروژه حرفه‌ای هم‌سطح عملکردهای عملیاتی Microsoft Project و Primavera P6:** **هم‌تراز با متره، نه قابلیت فرعی یا صرف گانت**. موتور واقعی CPM با Float و Longest Path، برنامه مبنا و Data Date، Actual، منابع و تراز، مقدار→مدت و هزینه، EVM، کنترل چندپروژه و تبادل داده با مرجع معتبر و گزارش کارگاهی. مرجع اجباری PC01–PC16: `docs/acceptance/phase8_p2/PROJECT_CONTROL_MSP_P6_PARITY_GATE_FA.md`. تطبیق با نرم‌افزار مرجع، Golden Project واقعی و تست Windows الزامی است؛ `MSP_PARITY/P6_PARITY=NOT_VERIFIED` تا مدرک واقعی.
**دو زیرمسیر A و B هم‌وزن از نظر ضرورت فنی و مستقل از نظر پذیرش‌اند؛ هیچ‌کدام با سبز بودن CI قبلی به‌طور خودکار بسته نمی‌شوند.** کدهای موردنیاز در محدوده دامنه پیشین فازهای ۲/۴/۸ اصلاح و یکپارچه شوند؛ اگر الزامی فراتر از دامنه قبلی باشد، آن را شفاف و بدون تغییر درصد ثبت کنند. فاز ۸ جای گسترش بی‌پایان محصول نیست.

## اصل تصمیم و جلوگیری از برچسب «تکمیل» نادرست
- **وضعیت موتور متره:** بهبود و رفع نقص گزارش شده است؛ `100_PERCENT_REAL_DRAWING_ACCEPTED` در GitHub شاهد معتبر ندارد. مبدل DWG پیشین ۸ LINE جا انداخته؛ تشخیص و رد خروجی ناقص جایگزین اصلاح parser نیست. PDF نمونه دوم باید با ریزمتره صفحه‌به‌صفحه تطبیق شود.
- **وضعیت کنترل پروژه:** روابط FS/SS/FF/SF و شروع زودترین، تقویم شمسی، تراز ابتدایی اکیپ و برنامه هفتگی در کد دیده شده؛ این‌ها CPM کامل، EVM واقعی یا برابری P6 نیستند.
- نتیجه هر بخش فقط `PASS_VERIFIED / PARTIAL / NOT_TESTED / BLOCKED` با SHA، CI، آزمون واقعی، خروجی، اختلاف و reviewer. سنجش در Windows واقعی و منبع خصوصی فقط در محیط مجاز.
- هیچ برنامه/قلم/نرخ/تاریخ/شکل یا ثبت مالی جعلی، هیچ حذف تست، هیچ انتشار خودکار، هیچ گسترش فاز/اولویت؛ همان ۸ فاز، ۶ اولویت ثابت فاز ۸، **یک نسخه کامل Windows**.
- **NO_MERGE/NO_MAIN_WRITE/NO_EXE/NO_INSTALLER/NO_RELEASE** بدون تأیید صریح مالک.
