# StructuralPro — فاز ۱، بسته ۴ Chat، گام دوم: پنج خانواده معماری

مبنای آزمون و اضافه‌کردن کد: PR #18، HEAD والد `803d45f071db2fd8a926cb63634acbb633b401b8`.

## دامنه
پنج شناسه از مجموعه ۳۷ خانواده دارای شواهد تخصصی ناکافی:
- `gypsum_partition`: دیوار خشک
- `cement_render`: اندود سیمانی
- `door_window`: در و پنجره
- `upvc_aluminium_windows`: پنجره UPVC/آلومینیوم
- `glass_curtain_wall`: نمای شیشه‌ای

این‌ها قرارداد عمومی `core/takeoff/reviewed_aec.py` دارند. مستقل‌بودن این فایل آزمون برای هر نام خانواده، معادل وجود موتور و فرم تخصصی مهندسی نیست. هیچ محاسبه واقعیِ پنجره، مساحت دیوار، قاب، مدول‌بندی و پرت به‌صورت حدسی ساخته نشده است.

- ۵ رد شناسه تکراری در همان جزء.
