# مرحله۱: اصلاح قطعی، کسورات و جدول مشترک
وضعیت کل مرحله: PARTIAL_NOT_ACCEPTED. مرحله۲ شروع نشده است.

## پیاده‌سازی و آزمون موفق
- دفتر اصلاحیه مستقل MA-UUID، نسخه/علت/سازنده/بازبین و snapshot/hash مبنا. اصل manual_formula_register وtakeoffs قطعی ثابت‌اند؛ فقط نمای مؤثرBOQ به کمک همان rebuild_project_boq تغییر می‌کند. موتور یاSQLite موازی ساخته نشده است.
- خودبازبینی، اعمال بدونبازبینی، تکرار، مبنای کهنه و تغییر مستقیم اصل/BOQ مسدودند. هر اصلاح تازه به نسخه مؤثر جاری متصل است. تاریخچه اصلاحیه قبلی باقی می‌ماند.
- پروژه دارای صورت‌وضعیت/برآورد/قرارداد/درخواست مالی/نرخ/سیاست مالی نیازمند گردش مالی مستقل است وapplyمسدود می‌شود. هیچ سند صادرشده یا قرارداد قبلی تغییر نمی‌کند. تغییر هویت/واحد/محل/مراجع ردیف قطعی و اصلاح وابسته قطعی هم مسدود است؛ گردش گروهی قطعی/مالی مجوز مستقل می‌خواهد.
- رقابت دوprocessواقعیspawn: یکAPPLIED،یکBLOCKED؛SQLiteCAS موجود، یک منبع ویکBOQ. بازگشاییSQLite اصلاحیه مؤثر را دوباره محاسبه می‌کند، درحالی‌که اصل مقدار قبلی محفوظ است.
- فرم فارسی کسورات درManualDialog موجود: منبع هندسی، نامپارامتر،مقدار،واحد،مبنا؛ افزودن/اصلاح/حذف نسخه‌دار. مقدارقبل/خالص/کسر مؤثر باevaluatorDecimal موجود، بدون درصد یا بازشوی حدسی. منبع وواحدنامعتبر، منفی،NaN،تکراری وnetمنفی رد می‌شوند. هرکسر باید دقیقاً یکبار درفرمول کم شود؛ geometryIDازناممتغیر جداست.
- کسورات قطعی ازهماناصلاحیه مستقل عبورمی‌کنند؛ مستقیمویرایش نمی‌شوند. گزارشExcel/PDF کسورات، منبع هندسی، قبل/بعد ودفتر اصلاحیه را دارد.
- یک جدول مشترک برایپیش‌نمایش تخصصی وفرمول، باشناسهproviderداخلی؛ انتخابمخلوط درعملیاتفرمول رد می‌شود تا ردیف اشتباه تغییر نکند. فیلتر/طبقه/عضو/وابستگی محفوظ؛ خطاها درهردو مسیر دیده می‌شوند.
- حذف پیش‌نویس وUndo/Redoواقعی پایدارSQLite، شناسه منبع ثابت وrevisionافزایشی؛ تأیید قدیمی احیا نمی‌شود. حذفمرجعِ دارایوابسته یافرمولBOQقطعی ممنوع است. Snapshotواگرد باJSON/zlibبدونحذفدقت فشرده می‌شود؛ historyخوانای قبلی باقی است.
- nativeQt/QTest: افزودن/اصلاح/حذفکسر،Undo/Redo،حذف/بازیابیفرمول وcreate/review/applyاصلاحیه باکلیک وscrollواقعی. همانپنجره،جدول،Service،DBوevaluatorموجود؛ هیچ پنجره/موتورموازی نیست.

## نیازمند پذیرش واقعی Windows
GUI/DPI/چاپ،MicrosoftExcelبازحسابواقعی،فونتهایWindows ونصب. پنجSkipPowerShellقبلی حفظ می‌شوند؛Buildاجرا نشده است. Linuxoffscreenوداده‌هایصریحمصنوعی جایپذیرشمهندس واقعی نیستند. نامبازبین محلی، احرازهویتسازمانی یااختیارواقعیمالک نیست.

## نواقص باقی‌مانده
مرتب‌سازی عددی کامل،انتقالمحل/طبقه یکپارچه،فرمفیلدمتناسبهمهگروه‌ها،فارسی‌سازی تمامپارامترهای مسیرقدیمی وUXپیشرفته همچنانباقی‌اند. Undoبعدازاصلاحقطعی اگرsnapshotقدیمی موجب تغییرمقدارقطعی شودFail-Closedمی‌ماند؛ اینتوقف عمداًتأیید قدیمی را برنمی‌گرداند. گردشگروهی اصلاحوابستگانقطعی/مالی درایننوبت پیاده نشده وبه‌عنوانپذیرفته اعلام نمی‌شود.

سناریوی۷۰ردیفیقبلی حذف/تضعیفنشده،درجامعنهایی اجراخواهدشد؛آزمونهدفمندقدیمی بی‌دلیل تکرار نشد. RED/GREEN/جامع/exitواقعی،بکاپexactHEAD/manifest/SHA/Git/SQLite دربسته تحویل حفظ می‌شوند. هیچMerge/main-change/ForcePush/Actions/workflow-change/Build/EXE/Installer/Release/StructuralBot-change انجام نشده است.
