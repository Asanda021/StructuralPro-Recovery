## تغییرات واقعی
1. `app/main.py`: عرض حداقل پنجره از ۱۱۸۰ به ۹۸۰ پیکسل تغییر کرد؛ Ribbon به QScrollArea افقی برای دسترسی به همه فرمان‌های واقعی در پنجره محدود منتقل شد، بدون نوار کناری دائمی. `QTabBar` نام قابل دسترس و هر عمل Ribbon نام/Tooltip دریافت کرد.
2. `app/desktop_shell.py`: دکمه واقعی جمع/بازکردن Ribbon + میانبر `Ctrl+Shift+R`، ذخیره وضعیت با QSettings و حفظ آن هنگام تعویض تب، انیمیشن کوتاه ارتفاع با گزینه خاموش‌کردن. میانبرهای `Ctrl+1/2` داشبورد/پروژه اضافه شدند.
3. `app/desktop_preferences.py`: کنترل واقعی نماهای شیشه‌ای Qt و ساده/غیرشفاف برای سخت‌افزار ضعیف؛ تنظیمات تم روز/شب و کاهش حرکت حفظ و در QSettings ذخیره شدند؛ انتخاب فونت واقعاً نصب‌شده با اولویت پشتیبانی خط عربی/فارسی به‌جای فهرست CSS نامطمئن.
4. `tests/test_phase6_p1_shell.py`: تست برنامه واقعی Qt برای Navigation/RTL، دکمه‌های ظاهر، ذخیره تنظیمات، Ribbon، تداوم در تغییر تب، نبود نوشتن داده پروژه، و دو اسکرین‌شات تم روز/شب در CI ویندوز.
5. `.github/workflows/phase6-p1-windows-shell.yml`: Linux 24.04 و Windows Server 2022، Python 3.12، PySide6/Qt offscreen، JUnit و PNG.
