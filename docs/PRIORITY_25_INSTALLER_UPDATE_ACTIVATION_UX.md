# Priority 25 — Installer / Update / Activation UX

این اولویت لایه تجربه کاربری انتشار را تکمیل می‌کند، بدون افزودن updater شبکه‌ای یا قرار دادن کلید خصوصی در کلاینت.

## موارد
- مقایسه نسخه به‌صورت عددی MAJOR.MINOR.PATCH
- وضعیت خوانای فعال‌سازی
- پیام مشخص برای نسخه جدید یا به‌روز بودن
- مسیر نصب فعلی همچنان offline-first و قابل بازتولید است
- activation verification همچنان fail-closed است.

Updater واقعی، سرویس انتشار و زیرساخت صدور مجوز در محیط تجاری بیرونی باقی می‌مانند.
