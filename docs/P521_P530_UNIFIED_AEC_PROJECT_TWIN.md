# P521–P530 — Unified AEC / Building Project Twin

## Purpose
Create a deterministic traceability contract connecting source, element, quantity and BOQ identity across AEC disciplines.

## Rules
- A link retains project revision and source identity.
- Structural, architectural, mechanical, electrical, civil and general domains are explicit.
- Source → element → quantity → BOQ traceability is represented as one auditable link.
- Missing identity or invalid domains fail closed.
- This contract does not invent quantities or perform hidden engineering calculations.
