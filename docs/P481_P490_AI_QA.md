# P481–P490 — AI QA

## Purpose
Provide a deterministic, evidence-first QA boundary for AI-assisted engineering workflows.

## Rules
- QA findings must retain source evidence and revision.
- AI findings are review artifacts, not authoritative engineering calculations.
- Unaccepted evidence cannot create findings.
- Unresolved error findings block acceptance.
- Open warnings require review.
- Resolved findings can pass the QA gate.
- No hidden engineering values or automatic data mutation.
