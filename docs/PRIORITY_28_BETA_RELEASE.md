# Priority 28 — Beta Release

این مرحله یک release gate قابل اجرا برای Beta تعریف می‌کند؛ خود gate نسخه را منتشر یا ادعای آماده‌بودن محصول نمی‌کند.

## Gateها
- VERSION معتبر
- Golden benchmark آماده
- مستندات کاربر و نصب آماده
- Windows packaging آماده
- نبود blocker ثبت‌شده

همه gateها باید همزمان برقرار باشند تا Beta به‌عنوان ready علامت بخورد.

## اصل
Beta release باید بر اساس evidence واقعی build و تست باشد؛ وجود فایل یا نام capability به‌تنهایی evidence محسوب نمی‌شود.
