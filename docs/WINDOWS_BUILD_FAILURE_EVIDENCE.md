# توقف ساخت ویندوز در خطای ابزار — فاز ۱۳

پایه: `ad071d843428b210dc39b3f854e3bc9984448922`.

اسکریپت ساخت اکنون کد خروج پنج مرحلهٔ ارتقای pip، نصب وابستگی‌ها،
PyInstaller، بازیابی و انتشار پل DWG را بلافاصله بررسی می‌کند.
وجود exe یا VERSION قدیمی نمی‌تواند شکست همین مرحله را به ساخت موفق تبدیل کند.

آزمون PowerShell اسکریپت واقعی را در پوشهٔ موقت با payload قدیمی اجرا می‌کند؛
ابزارها با فرمان‌های کنترل‌شدهٔ دارای LASTEXITCODE ناموفق جایگزین می‌شوند.
هر پنج شکست باید در همان مرحله متوقف شوند و فایل checksum ساخته نشود.
گردش‌کار Windows Release این آزمون‌ها را پیش از ساخت اجرا می‌کند.
در محیط فاقد PowerShell آزمون صریحاً skipped است؛ این حالت شاهد موفقیت نیست.

پشتیبانی IFC در نصب‌کننده، پذیرش Windows/DPI و سناریوهای واقعی ساختمان
همچنان باز هستند. این اصلاح تکمیل فاز ۱۳ یا فاز دیگری را اثبات نمی‌کند.
