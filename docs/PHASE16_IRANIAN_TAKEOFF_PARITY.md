# Phase 16 — Iranian Quantity Takeoff Parity

Implemented executable parity service for Iranian workflows: ریزمتره، خلاصه متره-ready rows، BOQ، واحدها، نسخه‌های فهرست‌بها، رشته/گروه، فصل، ضرایب صریح، import/export فهرست‌بها، snapshot قیمت، کاتالوگ اعضای بتنی و payload قابل انتقال پروژه.

Official price values are never fabricated. Coefficients are explicit and auditable. Project payloads are schema-tagged for backup/import compatibility.

Acceptance requires implementation, tests, CI, merge and post-merge main verification.
