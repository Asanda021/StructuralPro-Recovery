# Phase 18 — PDF Takeoff

این فاز یک Workbench یکپارچه برای متره گرافیکی PDF روی موتورهای موجود ایجاد می‌کند.

پوشش:
- مدیریت Sheet/Page
- Scale و منبع کالیبراسیون
- Length / Area / Volume / Count
- Markup / Annotation
- Crop / Cutout
- Measurement History
- Undo / Redo
- خروجی داده‌ای قابل اتصال به گزارش و BOQ

اصل ایمنی: این لایه هیچ مقیاس، هندسه یا مقدار مهندسی را حدس نمی‌زند و داده مبهم را fail-closed می‌کند.
