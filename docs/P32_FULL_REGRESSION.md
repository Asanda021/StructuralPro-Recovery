# P32 — Full Regression

P32 is the master cross-surface regression gate covering core functionality,
domain outputs, UI surfaces, data integrity, release artifacts, production
boundaries and release health. It composes the P30 hardening and P31
commercial-readiness gates.

Acceptance: Implementation → Tests → CI → Merge → Post-Merge Main Verification.

P32 does not fabricate customer projects and does not change engineering
quantity/calculation contracts.
