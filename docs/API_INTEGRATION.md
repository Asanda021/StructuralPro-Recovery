# StructuralPro / ERVIRA Integration

ERVIRA owns customer identity, commerce and entitlement presentation. StructuralPro owns the installed application and local runtime.

Integration requires authenticated customer identity. Secrets and payment-method data are not stored in the application. Download and feature access are entitlement-bound and fail closed without valid authorization.

The canonical product VERSION, Release Registry and verified artifact hashes are authoritative. Production credentials, tokens and customer data must never be committed to documentation.
