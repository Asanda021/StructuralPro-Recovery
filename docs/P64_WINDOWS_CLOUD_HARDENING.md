# P64 — Windows Product + Cloud Collaboration Hardening
## Windows
x64/ARM64 release identity, SHA-256 integrity, stable/beta channels, minimum Windows version, offline workspace, autosave/recovery, clean install, upgrade, rollback and uninstall are explicit and fingerprinted.
## Cloud
Owner/admin/editor/reviewer/viewer roles, revisioned events, stale/duplicate protection, base-fingerprint conflict detection, fail-closed permissions and deterministic three-way conflict reporting are executable.
## Boundary
No external cloud, CDN, identity provider, signing authority or deployed installer is claimed without infrastructure evidence.
