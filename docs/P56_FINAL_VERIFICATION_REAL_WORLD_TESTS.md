# P56 — Final Verification & Real-World Test Gate

## هدف

P56 دو کار را پوشش می‌دهد:
1. اجرای Regression و Smoke کامل در CI برای اطمینان از اینکه زنجیره فعلی پروژه پس از P55 نشکسته است.
2. آماده‌سازی قرارداد قابل‌اعتماد برای تست با پروژه‌های ساختمانی واقعی، بدون ساختن یا ادعای نتیجه جعلی.

## قانون مهم

تا وقتی فایل واقعی پروژه و متره مرجع انسانی در اختیار سیستم نباشد، هیچ Accuracy، Error، Success یا پوشش واقعی اعلام نمی‌شود.

تست‌های موجود در tests/test_p56_final_verification_real_world.py فقط Contract Test هستند؛ داده داخل آن‌ها نتیجه پروژه واقعی نیست.

## Evidence موردنیاز
- شناسه یکتا پروژه
- فایل واقعی نقشه یا مدل
- SHA-256 هر فایل
- زمان ثبت Evidence
- متره مرجع انسانی
- خروجی StructuralPro
- واحد هر قلم
- مقدار مرجع و مقدار سیستم
- توضیح اختلاف و تصمیم Reviewer در صورت نیاز

## انواع فایل
pdf, dwg, dxf, image, ifc, boq, report

## معیارهای مقایسه
برای هر قلم Absolute Error و Relative Error در صورت امکان محاسبه می‌شود. همچنین مجموع خطای مطلق، میانگین خطای نسبی و Fingerprint قطعی ثبت می‌شود. تقسیم بر صفر برای مقدار مرجع صفر انجام نمی‌شود و به صورت fail-closed مدیریت می‌شود.

## Regression Gate
Workflow مربوط به P56 این موارد را اجرا می‌کند:
- نصب وابستگی‌ها
- compileall برای core، app و tests
- اجرای کامل pytest
- اجرای تست اختصاصی P56

سبز شدن CI فقط سلامت اجرای نرم‌افزار و قراردادهای تست را ثابت می‌کند و به تنهایی اثبات‌کننده Accuracy متره روی پروژه واقعی نیست.

## گام بعد برای Evidence واقعی
فایل‌های واقعی یک یا چند پروژه ساختمانی به همراه متره مرجع باید ارائه شوند. پس از دریافت آن‌ها، همین قرارداد برای ثبت نتایج واقعی استفاده می‌شود.
