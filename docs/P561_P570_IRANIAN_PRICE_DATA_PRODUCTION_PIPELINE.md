# P561-P570 — Iranian Price Data Production Pipeline

## هدف
ساخت مرز تولید و مصرف داده قیمت برای بازار ایران با provenance کامل و بدون ساختن قیمت یا تبدیل پنهان.

## داده اجباری
هر PriceRecord شامل:
- Item Code
- Description
- Unit
- Rate
- Currency
- Effective Date
- Source ID
- Source Version
- Provenance Reference

## قواعد
- فقط ارزهای قراردادی IRR و IRT پذیرفته می‌شوند.
- Rate باید Decimal، متناهی و غیرمنفی باشد.
- قیمت بدون منبع و نسخه منبع معتبر پذیرفته نمی‌شود.
- Item Code در یک catalog نباید تکراری باشد.
- انتخاب قیمت بر اساس آخرین رکورد دارای تاریخ اعتبار <= تاریخ هدف انجام می‌شود.
- هیچ تبدیل ارز، escalation، inflation یا index adjustment به‌صورت پنهان انجام نمی‌شود.
- نبود قیمت معتبر باعث fail-closed می‌شود.

## اصل مهم
این فاز «داده قیمت» را تولید نمی‌کند؛ «pipeline قابل اعتماد برای ورود، اعتبارسنجی، fingerprint و انتخاب داده قیمت دارای منبع» ایجاد می‌کند. مقدار واقعی قیمت باید از منبع معتبر وارد شود.

## معیار پذیرش
1. fingerprint deterministic باشد.
2. provenance اجباری باشد.
3. رکورد تکراری رد شود.
4. قیمت آینده برای تاریخ گذشته انتخاب نشود.
5. ارز یا نرخ نامعتبر fail-closed شود.
6. هیچ تبدیل یا ضریب اقتصادی پنهان وجود نداشته باشد.
