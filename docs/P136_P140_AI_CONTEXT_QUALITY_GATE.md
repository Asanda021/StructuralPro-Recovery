# P136-P140 — AI Context & Quality Gate

این بسته یک لایه کنترل کیفیت برای دستیار هوشمند StructuralPro است و داده ساختگی تولید نمی‌کند.

- P136: زمینه و دامنه پروژه و ردیابی هر مقدار به منبع
- P137: تشخیص اقلام موردنیاز مفقود
- P138: کشف اختلاف مقدار بین منابع و شیت‌ها
- P139: کنترل شکاف اطلاعات مشخصات فنی
- P140: کنترل ریسک برآورد، از جمله مقدار یا قیمت نامعتبر

سه خروجی:
- pass: بدون خطای بحرانی و بدون هشدار
- review: بدون خطای بحرانی ولی نیازمند بررسی انسانی
- fail: حداقل یک خطای بحرانی

این فاز محاسبات طراحی سازه انجام نمی‌دهد و قابلیت خارجی بدون شواهد ادعا نمی‌کند.
