# P28 — Product UX Master Audit

## هدف

یک ممیزی نهایی و قابل‌تکرار برای تجربه کاربری محصول دسکتاپ StructuralPro، بدون تغییر در منطق مهندسی، محاسبات، BOQ یا قراردادهای داده.

## دامنه

P28 وضعیت فعلی UX را از روی قراردادهای واقعی مخزن بررسی می‌کند:

- ناوبری گروه‌بندی‌شده و قابل فهم
- میانبرهای اصلی و عملیات سریع
- RTL واقعی رابط دسکتاپ
- focus / disabled / tooltip و دسترسی‌پذیری پایه
- توکن‌های بصری مشترک برای اکشن‌ها، KPI، عنوان صفحه و ناوبری
- وجود سطح عملیاتی متره از نقشه
- اتصال کنترل کیفیت به validation واقعی و جلوگیری از وضعیت سبز ساختگی
- وجود regression test برای قراردادهای UX

## Fail-Closed

اگر هر مدرک لازم وجود نداشته باشد، ممیزی سبز نمی‌شود. این ممیزی صرفاً با مشاهده قراردادهای موجود تصمیم می‌گیرد و هیچ مقدار مهندسی یا وضعیت محصول را حدس نمی‌زند.

## پذیرش

اجرای:

`pytest -q tests/test_p28_product_ux_master_audit.py tests/test_ui_design_system.py tests/test_priority_47_ui_functional_audit.py`

باید بدون خطا تمام شود.

پس از آن، CI کامل پروژه و Post-Merge Main Verification باید سبز باشند.

## مرز

P28 ممیزی UX است؛ طراحی سازه، محاسبات، متره، قیمت‌گذاری و داده‌های مهندسی را تغییر نمی‌دهد.
