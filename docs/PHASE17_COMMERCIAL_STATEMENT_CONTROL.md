# Phase 17 — صورت‌وضعیت و Commercial

این فاز لایه تجاری را از «محاسبه صرف» به یک کنترل یکپارچه و قابل ممیزی برای قرارداد، پیشرفت، کسورات و مقایسه برآورد/عملکرد می‌رساند.

## دامنه تکمیل‌شده
- آیتم‌های قراردادی و مبلغ قرارداد
- مقدار انجام‌شده در دوره، قبلی و تجمعی
- جلوگیری قطعی از عبور مقدار تجمعی از مقدار قراردادی
- کسورات شفاف: تضمین، استهلاک/بازگشت پیش‌پرداخت، مالیات، بیمه و سایر
- وضعیت قرارداد: پیشرفت، باقی‌مانده، پرداخت‌شده، مطالبات انجام‌شده و تعهدات جاری
- گزارش مالی تجمیعی دوره‌ها
- مقایسه Estimate با Actual به تفکیک آیتم و تشخیص over-budget
- خروجی داده‌ای قابل اتصال به UI/Excel/PDF موجود

## اصل داده
هیچ نرخ رسمی، قیمت فهرست‌بها، مالیات یا بیمه از خود سیستم جعل نمی‌شود؛ مقادیر و نرخ‌ها باید از قرارداد/داده معتبر پروژه وارد شوند.

## Gate
Implementation → Dedicated Tests → CI → Merge → Post-Merge Main Verification.
