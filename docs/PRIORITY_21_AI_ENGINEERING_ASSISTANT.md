# Priority 21 — AI Engineering Assistant

## هدف
تبدیل لایه AI موجود به یک دستیار مهندسی قابل‌اعتماد، توضیح‌پذیر و review-first، بدون تبدیل AI به موتور محاسبات یا عامل خودکار.

## قابلیت‌ها
- تشخیص نیت پروژه، متره، BOQ، گزارش، گردش‌کار، کتابخانه مهندسی و BIM/CAD
- ساخت context محدود و قابل ردیابی از پروژه
- استفاده از validation موجود به‌عنوان evidence
- پاسخ توضیحی با منشأ داده
- proposal برای عملیات اثرگذار به‌جای اجرای خودکار
- confirmation gate برای درخواست‌های تغییر/ثبت/حذف
- بدون API خارجی و بدون الزام مدل زبانی

## مرز محصول
AI فقط inspect/classify/suggest/explain می‌کند. مقدار، قیمت، محاسبه مهندسی یا تغییر داده را مخفیانه تولید یا اعمال نمی‌کند. هر عملیات اثرگذار باید توسط لایه کاربردی و پس از تأیید صریح کاربر اجرا شود.

## سازگاری
این لایه کنار LocalAIEngine، ProjectAssistant، LocalTakeoffAssistant و QA موجود قرار می‌گیرد و APIهای قبلی را حذف یا تغییر نمی‌دهد.
