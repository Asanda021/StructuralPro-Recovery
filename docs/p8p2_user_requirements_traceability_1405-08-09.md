# StructuralPro — کنترل جامع خواسته‌های کاربر، فاز ۸ / اولویت ۲
**تاریخ مبنا:** ۱۴۰۵/۰۸/۰۹ (۳۱ اکتبر ۲۰۲۶).  
**دامنه:** درخواست‌های این گفت‌وگو درباره بازکردن، نمایش، انتخاب ناحیه، متره، تشخیص سازه، انتخاب رشته، برنامه زمان‌بندی و ارتباط با برآورد؛ قیود ثابت پروژه.  
**سیاست:** تنها ۸ فاز، ۶ اولویت ثابت فاز۸. بدون Merge، ساخت EXE، آپلود فایل خصوصی یا تأیید هزینه/BOQ حدسی.

معانی وضعیت:
- **پیاده‌سازی و آزمون هدفمند**: کد و تست مرتبط وجود دارد و باید نتیجه CI همان HEAD مجدداً بررسی شود؛ آزمون نمونه مصنوعی هرگز پذیرش منبع واقعی نیست.
- **ناقص**: بخشی از مسیر وجود دارد اما یک یا چند جزء لازم/سنجش مهندسی ندارد.
- **باز / اثبات‌نشده**: قابلیت کامل یا شاهد پذیرش وجود ندارد. «بدون حذف خاموش» به معنی تضمین این نیست که decoder اولیه اصلاً چیزی را حذف نمی‌کند.

## شواهد فنی و قیود باز
1. **AutoCAD 2027**: جدول رسمی Autodesk (۲۷ مه ۲۰۲۶) همان DWG 2018/AC1032 را تا ۲۰۲۷ اعلام کرده است. این کافی برای ضمانت AEC/Mechanical/Civil 3D/Proxy نیست.
2. **منبع اصلی کاربر** `naghshe ha.dwg` با هدر AC1018 و فایل Excel ۱۸ شیت/۱۴۳ ردیف: تحلیل هندسی کامل و تطبیق واقعی روی Windows **انجام نشده**. فایل خصوصی را در GitHub منتشر نکنید.
3. **کمیت‌ها/محاسبات**: بازشناسی متن/لایه‌ها، نمایش CAD و برنامه پیشنهادی نه مجوز اصلاح عددهای BOQ است و نه مجوز نرخ بهره‌وری/تاریخ پایان.
4. **CI**: هدفمند Windows/Linux روی `8ce91cf0` سبز؛ رگرسیون گسترده Linux روی همان SHA یک شکست Qt متوالی `test_crosswalk_close_does_not_call_deleted_scene` داشت (۶۴۳ PASS + ۱ FAIL). رفع در commitهای بعدی و نیازمند بازآزمایی همان HEAD است.
5. وضعیت کلی رسمی این حوزه: **P8/P2 = PARTIAL / NO-GO** تا اجرای واقعی فایل منبع، آزمون AEC/MEP/SHX/large Windows و CI جامع. پیشرفت گزارش‌شده کل پروژه **۸۹٫۶٪** فعلاً بدون تغییر؛ هشت فاز تثبیت‌شده و فاز۸ شش اولویت دارد.

### معیار پذیرش نهایی ثابت این اولویت
- Windows 2022/11: پروژهٔ واقعی AC1018 و نقشه واقعی ذخیره‌شده با AutoCAD 2027؛ import/reopen/scope/zoom/edit/export و تمام اجزا حسابرسی‌شده بدون حذف خاموش؛ موارد ناممکن با اخطار.
- تست نقشه سنگین واقعی با شاخص‌های مصرف حافظه و پاسخ UI؛ ابزار cancel و نگهداری provenance سالم.
- تطبیق ریزمتره واقعی با شواهد CAD و اکسل مستقل، وضعیت ۱۴۳ ردیف بدون false positive.
- ساخت برنامه متره‌محور با انتخاب رشته، تقویم، اکیپ/نرخ واقعی، Gantt، ذخیره/بازیابی، کنترل خطا و خروجی حرفه‌ای.
- همه CIهای مرتبط روی **یک SHA واحد** سبز، هیچ Merge بدون تأیید مالک.

**این سند معیار پذیرش است؛ جایگزین پیاده‌سازی موارد باز نیست.**
