# P58 — Real Price Data Calibration

این فاز لایه Evidence برای ورود و کالیبراسیون قیمت‌های واقعی را اضافه می‌کند.

هر نرخ باید منبع، نام فهرست/لیست قیمت، نسخه، تاریخ اثرگذاری و زمان ثبت داشته باشد. نرخ بدون منبع معتبر یا نرخ متناقض برای یک قلم، واحد و ارز پذیرفته نمی‌شود.

این فاز **هیچ قیمت بازار یا قیمت رسمی ایران را از خودش تولید نمی‌کند**. داده واقعی باید از فهرست‌بها/منبع معتبر و با نسخه و تاریخ مشخص وارد شود.

برای هر نرخ:
- کد قلم
- شرح
- واحد
- مبلغ
- ارز
- منبع
- نام فهرست
- نسخه
- تاریخ اثرگذاری
- زمان مشاهده
- Fingerprint

در نتیجه، قیمت‌گذاری StructuralPro قابل Trace و بازتولید می‌شود و نرخ‌های متناقض fail-closed می‌شوند.

Contract Testهای P58 فقط سلامت منطق را بررسی می‌کنند و نتیجه قیمت واقعی بازار محسوب نمی‌شوند.
