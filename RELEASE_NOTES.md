# StructuralPro Release Notes

## 0.1.0

This release is CI-buildable for Windows and is subject to the release-delivery gates defined in P61-P70.

### Delivery evidence
- Windows executable: generated by the Windows release workflow.
- Windows installer: generated and installation-smoke-tested by the Windows release workflow.
- SHA-256: generated and verified by the Windows release workflow.
- Release registry: generated from the verified release manifest.

### Customer availability
Customer download remains entitlement-authorized. Build/installer CI evidence does not by itself make a customer release live.
